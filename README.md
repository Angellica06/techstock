# 📦 TechStock

Projeto de um sistema web para gerenciamento de estoque, permitindo o controle de produtos, cadastro, atualização de informações e acompanhamento da quantidade disponível.

## 🚧 Status do Projeto

Em desenvolvimento.

## 🛠️ Tecnologias utilizadas

- React
- React Router
- JavaScript
- Vite
- Tailwind CSS
